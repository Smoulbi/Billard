# Instructions pour le projet Billard

- À chaque nouvelle modification demandée par l’utilisateur et livrée, incrémenter
  la version du projet, une fois par mise à jour (par exemple 0.59 → 0.60).
- `VERSION` contient le numéro courant. Mettre aussi à jour les versions affichées
  dans `dist/index.html` (en-tête, pied de panneau et BUILD), les paramètres `v`
  des liens JavaScript/CSS et la version courante du README de démarrage.
- Conserver les documents et notes de versions historiques sans réécrire leurs
  anciens numéros. Les corrections pendant une même mise à jour utilisent la
  même nouvelle version.
- Vérifier les changements avec les tests et contrôles adaptés à leur portée.
